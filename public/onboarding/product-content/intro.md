# Product Content

This guide demonstrates AI fields as a repeatable production system rather than a one-off chat response.

## Included table

`Product Content Studio.kitable` starts with product concepts and shows fields for:

- hero product images
- orthographic and feature views
- lifestyle images and style boards
- LinkedIn copy
- short social copy

Each generated field is tied to structured source columns, so you can review results row by row and regenerate only the cells that need work.

## Adapt it

Open an AI field configuration and choose a source field, model, output type, and instruction. For example:

```text
Create a clean studio product image on a white background using the concept description. Preserve the specified colors and materials.
```

Use a text-capable model for channel copy and an image-capable model for visual fields. AI fields run only when you trigger them or explicitly enable automatic regeneration.
